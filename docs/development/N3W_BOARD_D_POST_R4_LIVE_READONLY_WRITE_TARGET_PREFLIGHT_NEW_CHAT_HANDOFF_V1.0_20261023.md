## 10. Next ONE Gate

\`\`\`text
NEXT_ONE_GATE=N3W_BOARD_D_POST_R4_LIVE_READONLY_WRITE_TARGET_PREFLIGHT_20261023_01
\`\`\`

### Purpose

这一步只证明：

1. 当前通过 USB/ROM 接入的目标确实是一个 ESP32-C6；
2. Flash 为 8 MB；
3. Secure Boot 与 Flash Encryption 均处于可接受的关闭状态；
4. 观察到的物理目标由操作者确认就是 Board D；
5. 将该目标转换为公开安全的 \`hardware_id_sha256\`，为后续 Board D 身份冻结提供依据；
6. 只读回读现有 bootloader 与 partition table，并与 R4 V2 release 比较；
7. 根据比较结果决定后续写入路线候选：
   - 两者均匹配：\`APP_PLUS_OTADATA_CANDIDATE\`
   - 任一不匹配：\`FACTORY_OR_NORMALIZED_OFFSETS_REVIEW_REQUIRED\`

这一步 **不能证明**：

- Board D 已刷入 R4 固件；
- Board D pairing/telemetry/Direct/Relay 行为；
- RF 物理验收；
- 后续写入已经获得授权。

### Operations

\`\`\`text
1. fresh rebind repository main and verify the preflight executor blob.
2. fresh recheck R4 V2 artifact exists, is not expired, and exact digest still matches.
3. before any serial open, obtain explicit user authorization for this read-only physical gate.
4. user physically connects/identifies Board D only; enumerate the Mac serial locator without treating the path as identity.
5. run the repository-owned executor preflight with the exact inner release bundle.
6. executor validates the R4 release bundle and ESP32-C6 images.
7. executor performs get-security-info and flash-id.
8. executor derives hardware_id_sha256 from observed ROM identity; raw ROM MAC is not persisted in public evidence.
9. executor read-flash reads only bootloader and partition-table regions.
10. executor classifies the later write-mode candidate.
11. operator confirms that the physically connected device is Board D.
12. stop and review the preflight evidence. Do not write firmware in this gate.
\`\`\`
