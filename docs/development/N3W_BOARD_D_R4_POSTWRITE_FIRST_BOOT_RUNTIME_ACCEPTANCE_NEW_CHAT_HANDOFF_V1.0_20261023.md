
Rollback/停止原则：

```text
1. 在 application boot 前先 fresh 证明 Board D identity，并读取 preboot NVS hash。
2. 只执行一次受控正常 application boot。
3. 如出现异常 reboot / deep sleep / 无法证明 R4 application start，立即 STOP。
4. 不自动第二次 boot、不 reflash、不恢复 NVS。
5. 如 application runtime 导致 NVS 变化，只记录并分类；NVS hash 变化本身不自动判 FAIL。
```

### Purpose

这一步只证明：

1. 连接目标仍是 frozen Board D；
2. 写入后的 exact R4 能从正常启动路径进入 application；
3. application 能在 USB 供电条件下持续运行至少 90 秒；
4. 没有出现旧固件低电量保护/休眠逻辑造成的立即休眠、重复复位或明显 runtime 退出；
5. 记录首次运行前后的 NVS hash，区分正常 runtime 写入与异常持久变化。

- pairing 已完成；
- Manager/Broker/HA telemetry acceptance；
- Wi-Fi Direct / ESP-NOW Relay；
- RF failover / failback；
- 多 Relay gateway selection；
- 电池低电量阈值本身正确；
- 任何后续生产通信验收已通过。
