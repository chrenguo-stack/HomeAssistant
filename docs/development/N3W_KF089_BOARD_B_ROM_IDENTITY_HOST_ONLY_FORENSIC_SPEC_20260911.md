# N3-W KF-089 Board B ROM Identity Host-Only Forensic Specification — 2026-09-11

Status: `HOST_ONLY_NO_DEVICE_REOPEN`

## 1. Purpose

Investigate the consumed physical attempt that stopped at `ROM_IDENTITY_BINDING` without reconnecting to Board B.

The reviewed Guard currently:

1. runs the read-only esptool `read-mac` command;
2. persists `rom_identity_read.stdout.txt`, `.stderr.txt`, `.result.json`, and `.command.json`;
3. passes **stdout only** to `verify_identity_output()`;
4. extracts every colon-separated six-octet MAC-looking substring from that stdout into a set;
5. requires exactly one distinct candidate before it compares that candidate with the expected Board B identity.

Therefore the observed error `ROM identity output does not contain exactly one BASE_MAC` occurs before the expected-vs-observed identity comparison. It does not by itself prove that the connected device was not Board B.
