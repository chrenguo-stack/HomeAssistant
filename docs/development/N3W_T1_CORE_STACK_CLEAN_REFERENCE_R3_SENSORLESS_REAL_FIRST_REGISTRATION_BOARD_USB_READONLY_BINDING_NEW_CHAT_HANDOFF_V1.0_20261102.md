## 10. Next ONE Gate

```text
NEXT_ONE_GATE=N3W_T1_CORE_STACK_CLEAN_REFERENCE_R3_BOARD_USB_READONLY_IDENTITY_BINDING_20261102_01
```

### Purpose

证明用户本地唯一 USB 目标确实是预期的 ESP32-C6，并读取 Flash 基本身份/容量信息，为后续 exact factory image 写入建立物理目标绑定。

该 gate 不能证明：
- Board 是 fresh/unregistered；
- NVS 已清空；
- exact firmware 已写入；
- T1 registration readiness 的 fresh live 状态；
- first-registration 成功。

### Inputs

```text
TARGET_USB_LOCATOR=USER_PRIVATE_FRESH_ENUMERATION_REQUIRED
EXPECTED_CHIP_FAMILY=ESP32-C6
EXPECTED_PRODUCT_FLASH_SIZE=8MB
BOARD_SENSOR_PROFILE=SENSORLESS_WITH_LCD
CURRENT_HEAD=ea1488845ba05d362454678f2801232010852ecf
CURRENT_HEAD_ARTIFACT_CI=FRESH_RECHECK_REQUIRED
```

### Operations

```text
1. 用户 fresh 执行本地 USB modem 枚举，确认仍只有预期目标。
2. 用户执行只读 esptool chip-id。
3. 用户执行只读 esptool flash-id。
4. 高层模型分类输出；原始 MAC/芯片唯一身份不提交公开 GitHub。
5. STOP；不得在同一 gate 自动 erase/write。
```

### PASS / FAIL / STOP

```text
PASS_IF=TARGET_IS_ESP32_C6_AND_FLASH_ID_READABLE_AND_FLASH_CAPACITY_MATCHES_EXPECTED_PRODUCT_HARDWARE
FAIL_IF=WRONG_CHIP;AMBIGUOUS_USB_TARGET;FLASH_ID_UNREADABLE;UNEXPECTED_FLASH_CAPACITY
```
