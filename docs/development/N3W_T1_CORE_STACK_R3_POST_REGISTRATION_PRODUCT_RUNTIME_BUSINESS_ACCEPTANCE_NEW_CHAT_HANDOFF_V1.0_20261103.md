## 10. Next ONE Gate

```text
NEXT_ONE_GATE=N3W_T1_CORE_STACK_R3_POST_REGISTRATION_PRODUCT_RUNTIME_BUSINESS_ACCEPTANCE_READONLY_PREFLIGHT_20261103_01
```

### Purpose

This gate must establish a fresh, non-mutating baseline for the already-registered product state before downstream runtime/business acceptance starts.

It must prove or classify:

- repository/main and authority v2 still bind the b863 repaired Manager;
- current Manager/Broker/Home Assistant runtime is healthy and unchanged in identity;
- the committed registration, node lease and generation-1 credential assignment remain durable and internally consistent;
- no unresolved first-registration transaction exists;
- pairing is quiescent and 47112 is closed;
- passive Manager/Broker evidence can classify whether the registered node is currently online/authenticated and whether MQTT telemetry is visible;
- passive Home Assistant evidence can classify whether discovery/entity state is visible;
- the current board power/network state can be classified without powering, rebooting, flashing, opening serial or moving the board.

This gate does **not** prove sensor accuracy, active telemetry recovery, Direct/Relay failover or long-duration stability.

### Inputs

```text
INPUT_1=main@e0841a5a43fd5847d5c5c40ab1cece42faedf3c8

INPUT_5=registered_node_last_accepted_durable_state_without_public_raw_identity
```

### Operations

```text
1. Fresh rebind repository main and canonical authority; STOP on any source/authority drift.
2. Read-only inspect current Manager, Broker and Home Assistant runtime identity, restart counts, systemd health and listener contract.
3. Read-only inspect first-registration ledger, current registration, node lease, pairing session and credential-lifecycle assignment; preserve tombstones and secrets.
4. Read-only inspect pairing-window status and require no unexpected privileged pairing exposure.
5. Passively inspect Manager/Broker evidence for current node online/authenticated/telemetry visibility without changing credentials, subscriptions or Broker state.
6. Passively inspect Home Assistant state for discovery/entity visibility without changing HA configuration.
7. Classify registered-board current state only from available passive evidence; do not power-cycle, reconnect USB, open serial, reflash or move the board.
8. Produce one bounded readiness result for the first active downstream acceptance gate.
```
