## 恢复设计

| 发生位置 | 恢复要求 |
|---|---|
| U0–U6，应用仍运行 | 下载、USB 或归档检查失败时，旧版继续运行，给出具体原因。 |
| U7–U8，应用已停止 | 在时间预算内且证据一致时安全续接，否则核对旧镜像、配置和数据，启动旧版并验证用户功能。旧版重新写入后，下一轮重新生成一致性备份。 |
| U9 及以后 | 主机恢复程序先核对实际镜像、数据、已落盘阶段和绑定 USB，再选择续接或按既有流程恢复旧镜像及数据。健康校验通过后才报告恢复。 |
| U9 后缺少原 USB 或材料失效 | 原 USB 缺失时，用独立于应用服务的本地入口提示插回原盘，核对通过后续接。材料无法验证时进入维修状态。 |

在现有的主机升级服务中设计单一恢复协调逻辑，统一产品和验收工具的服务停止判据，处理备份完成后最后检查报错、进程退出、掉电、主机与 USB 分步落盘。关键动作前后保存事务、阶段、内容摘要和执行意图。重启后根据实际状态续接，只有证据匹配同一事务和合法相邻阶段时才补齐记录。恢复逻辑由主机负责，客户入口显示简短状态。回退到 U7 备份时，实测并说明升级窗口数据的保留情况。

停机计时从停止应用服务开始，结束于页面可打开、管理服务就绪以及新温室数据可见。切换前 5 分钟、切换后 15 分钟是首轮试验目标。留足回退预算后才尝试新版，停服务前判断窗口是否足够。用支持范围内的慢 USB 和大数据量重测，分别记录断电或等盘时间及条件恢复后的处理时间。U9 后限时恢复依赖仍可读取的同一文件系统 UUID 的原 USB。如果将来要求 USB 损坏也可限时恢复，先评估 T1 内部空间及独立恢复副本，另行决定。 [现有掉电恢复合同](./N3W_T1_HOMEASSISTANT_USB_MANDATORY_OTA_P5_SOURCE_DESIGN_DELTA_20261106.md#15-power-loss-recovery-contract)

## 2026-11-19 状态更新：U10 destructive 前新增 U9+ 限时恢复门禁

当前实机已经推进到 durable U9，并由 Attempt 05 在真实 T1 上完成 U10 只读预检：目标包、旧镜像恢复包、HA 数据备份、同一 USB 元数据、容量和 Broker 连续性全部重新验证通过；没有发生 U10 写入、旧镜像删除、目标加载或服务修改。KF-167 已物理关闭。

这说明“可以安全进入 destructive cutover 的技术前提”已经成立，但不等于“客户故障后能在约定时间恢复”的验收已经成立。现有 R2 rollback/power-loss 证明主要是 synthetic 事务模型；当前 P3 实机链路又因工程诊断在各阶段之间长期暂停，不能拿它的总停机时间作为客户恢复时长证据。

因此在 destructive U10 前新增正式门禁：先复核生产路径实际使用的 U9-U13 恢复协调器，补足必要的故障注入和 customer-visible health oracle，再在单独授权的实机破坏性验收中覆盖 U10/U11/U12 失败、断电、缺盘/原盘重插和慢盘/大数据场景。初始试验目标仍为切换前恢复不超过 5 分钟、切换后恢复不超过 15 分钟；实测前不对客户做正式时长承诺。

详见 N3W_T1_U9_PLUS_BOUNDED_RECOVERY_PRE_U10_GATE_20261119.md。

## 下一阶段顺序

1. **先调整验收。** 把 U7/KF-158 误判、备份完成后的异常和长期停机列入实机验收。产品控制器和验收工具共用判断，区分 `inactive` 与经核实已完全停止的 `failed`。主进程仍在、应用容器未退出或 Broker 连续性失效时停止推进。
2. **U8 可独立接续。** 先核对当前 P3 现场与回执。收到候选专属授权后，写入主机及 USB 的 U8 恢复验收记录，到 U8 即停。其通过条件是恢复材料、容量和事务记录准确，实机写入或阶段通过不等同于客户恢复验收。 [U8 候选说明](./N3W_T1_U13B_P3_U8_RECOVERY_ADMISSION_20261118.md)
3. **当前 T1 进入 U9 前，先在备用 T1 验证切换前恢复。** 复现 U7 最后一项检查报错、升级进程中断，以及主机和 USB 只写成一边。验证产品能据实续接或自动恢复旧版，并确认页面、历史数据和新数据。先核对备用 T1 与写入范围，再取得相应实机授权。
4. **之后推进 U9–U11，最终从客户入口验收。** 用最终交付版本覆盖正常升级、切换后目标启动/健康失败并回滚、断电续接、缺盘和原盘插回。记录可用版本、停机时长、历史数据读取与新数据恢复。以实测结果决定限时恢复承诺。专用阶段执行器的通过结果只用于相应阶段判断。
