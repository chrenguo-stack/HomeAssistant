## 10. Next ONE Gate

```text
NEXT_ONE_GATE=N3W_T1_F4_REBOOT_SUCCESSOR_CONTROL_APPLYING_RECOVERY_SOURCE_REPAIR_20261016_01
```

### Purpose

在仓库中实现一个专用、fail-closed、可测试的 `CONTROL_APPLYING` 恢复路径。它必须接纳已经消费的原安装
授权事实，但绝不能把该授权当成可重放；必须绑定原 installed bytes、原 claim、修复后的 exact package、
未变化的 F4/runtime/certificate/boot identities 和一个未来独立 recovery authorization。

本 gate 只能证明源码和离线/CI 合同正确，不能证明真实 T1 已恢复，也不能授权 reboot。

### Operations

```text
1. Fresh read-only rebind PR #605 head, tree, diff, branch status and CI; read the required context files.
2. Review authority/package builder/tests and freeze the minimal CONTROL_APPLYING recovery state machine.

4. Add focused positive and negative regressions for consumed-auth non-replay, exact old-target binding, drift rejection, partial failure, durable recovery claim and CONTROL_READY commit ordering.
5. Run focused pytest, public-repository safety checks and applicable local fast checks.
6. Push one bounded source/test/doc update to PR #605, observe exact-head CI at most three times, then perform the required focused source review.
7. Stop after source closure or on the first substantive blocker; do not enter live recovery.
```
