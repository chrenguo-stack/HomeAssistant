## 10. Next ONE Gate

```text
NEXT_ONE_GATE=N3W_T1_HOMEASSISTANT_USB_MANDATORY_OTA_P5_SOURCE_IMPLEMENTATION_R3_20261106_01
```

### Purpose

R3 要把已经通过 R1/R2 验证的 mandatory-USB transaction 能力投影成一个非特权 `greenhouse-manager` OTA 控制面：

- 读取/规范化“已批准的 Home Assistant 目标 manifest”；
- 计算 installed/latest/available/progress/phase 等 OTA 状态；
- 在 Home Assistant 中发布 MQTT Update discovery/state；
- 接收严格、有限、可验证的 PREPARE / INSTALL / STATUS intent；
- 保证 Manager 不能通过 MQTT 输入获得 host path、block device、Docker、shell 或 live authorization 控制能力。

R3 不能证明真实 USB、真实 Docker、真实备份或 live install；这些属于 R4/R5 及后续物理 gate。
