## 9. Rollback Authority

本 gate 允许创建 U1 transaction，但不允许删除/覆盖 transaction，也不允许任何 USB
介质 mutation。失败时只读归档状态并 STOP，不能把第二次 PREPARE 当作 rollback。

```text
ROLLBACK_BASELINE=FRESH_PRE_PREPARE_HEALTHY_STATE_PLUS_NO_ACTIVE_HA_USB_TRANSACTION_PLUS_ZERO_USB_LIKE_DISK
FRESH_PRECHANGE_SNAPSHOT_REQUIRED=true
ROLLBACK_AUTHORITY_PATH_OR_ID=OPERATOR_LOCAL_PRE_PREPARE_READONLY_EVIDENCE
RESTART_SCOPE_ALLOWED=NONE
SECOND_ATTEMPT_ALLOWED=false
AUTOMATIC_ROLLBACK_IN_GATE=false
ROLLBACK_FAILURE_CLASS=PREPARE_STATE_REQUIRES_SEPARATE_RECOVERY_CLASSIFICATION
```

失败处理：

```text
capture transaction/prepare state read-only
-> capture Manager/Home Assistant/Broker/host-daemon health read-only
-> do not delete/reset/overwrite transaction
-> do not restart services
-> do not re-press PREPARE
-> do not insert USB
-> STOP
```
