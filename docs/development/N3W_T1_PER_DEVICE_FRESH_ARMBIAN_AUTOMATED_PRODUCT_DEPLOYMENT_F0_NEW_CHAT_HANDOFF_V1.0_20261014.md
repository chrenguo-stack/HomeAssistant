### Purpose

F0 要证明现有 fresh-bootstrap、explicit provisioning、image delivery、activation 和 acceptance
源码中，哪些可以直接复用、哪些必须删除旧克隆分支、哪些需要进入 F1 修复。它还必须选择

传输、Docker mutation 或服务启动。

### Operations

```text
1. Fresh rebind main, PR #541, candidate head, ADR-0010, execution plan and exact CI.
2. Inventory active source/tests/workflows for minimal host, fresh bootstrap, image delivery, explicit provisioning, activation and acceptance.
3. Identify and quarantine or remove Golden Master, Seal and clone-only branches from the proposed active path.
4. Verify exact Manager, Home Assistant and Broker image publication/digest authority available to the new route.
5. Compare exact-digest target pull with one-image-at-a-time Mac stream and select one bounded default contract.
6. Recalculate peak T1 capacity for the selected contract without materializing all three image tar files together.
7. Freeze the smallest F1 source-change list, focused tests, CI set, rollback behavior and stop boundaries.
8. Commit public-safe F0 findings/closure to GitHub and update current state/index if F0 completes.
```
