```text
AUTOMATIC_ROLLBACK_IN_GATE=false
```

失败处理：

```text
capture current HA-USB transaction/state read-only
→ capture Manager/HA/Broker/host-daemon health read-only
→ do not delete/reset/overwrite transaction
→ do not restart services
→ do not re-press PREPARE
→ STOP
→ return to high-level model for separate recovery decision
```

### Operations

```text
1. fresh rebind PR #800, handoff, CURRENT_STATE, CURRENT_STATE_INDEX, KNOWN_FAILURES and Boundary B preexecution authority.
2. read-only verify A1R health: host daemon active, Manager OTA enabled, Manager/HA/Broker healthy, recovery clear.
3. read-only verify no active HA-USB transaction/PREPARE state and dedicated test USB absent.
4. capture fresh pre-PREPARE snapshot; if any drift exists, STOP before mutation.
5. invoke exactly one PREPARE through the product Home Assistant PREPARE control surface.
6. verify phase=USB_REQUIRED, usb_confirmation_required=false, candidate=null; verify no destructive action occurred.
7. only after step 6 PASS, instruct operator to insert exactly one dedicated removable test USB.
8. use read-only discovery evidence to require exactly one fresh eligible candidate.
9. verify final phase=USB_REQUIRED_CONFIRMATION, usb_confirmation_required=true, candidate model/capacity visible.
10. verify CONFIRM_USB_ERASE was not invoked and no wipefs/partition/mkfs/mount/target-download path was entered.
11. capture structured closure and STOP.
```
