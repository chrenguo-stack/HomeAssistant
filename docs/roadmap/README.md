# 技术路线文档

本目录只保存长期架构基线和接口路线，不保存会随 PR、CI、Artifact 或实机
测试不断变化的实时项目进度。

- `greenhouse-technology-roadmap-v0.6.md`：当前后继架构基线。
- V0.5 冻结版保留为历史文件，不做原位修改；与 V0.6 或 ADR 冲突时，按
  较新的已接受 ADR 和 V0.6 执行。
- 实时阶段状态放在 `docs/status/`。
- 对话切换与生产阶段交接放在 `docs/handoffs/`。
- 跨固件、主机和网关的冻结 topic/schema 放在 `protocols/`。

技术路线中的“冻结决策”“接口基线”和“待验证决策门”含义不同。接口写入
路线文档不代表已经完成模拟、实板、T1 或现场验收；完成状态必须由对应
状态文件和验收证据确认。
